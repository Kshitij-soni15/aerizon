AETHRIX — Driver Drowsiness Demo

EASIEST START:
1. Install Python 3.11.x on Windows.
2. Open this folder.
3. Double-click START_AETHRIX.bat.
4. Wait for installation on the first run.
5. A browser dashboard will open.
6. Allow camera permission.
7. Click Calibrate Driver Baseline.

The demo uses the laptop webcam and runs locally with Python, OpenCV and MediaPipe.
The laptop is only the prototype environment. The detection/risk pipeline is designed to be migrated to vehicle-facing camera + edge hardware later.

IMPORTANT:
- Do not use while actually driving.
- This is a prototype demonstration, not a certified safety device.
- If anything errors, take a screenshot of the black setup window and send it to ChatGPT.
